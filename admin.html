Panel del dueño

Editá el menú y generá el QR para imprimir en las mesas.

QR para la mesa

Este QR apunta a la página del menú público (index.html). Descargalo o hacé captura para imprimirlo.

Editar platos

Cambiá precios, marcá "agotado" o "plato del día", y al terminar tocá "Descargar menu.json" — reemplazá ese archivo en el repo (carpeta data/) y subilo a GitHub para publicar los cambios.

Guardar cambios

Esto genera el archivo actualizado. No se sube solo a GitHub — hay que reemplazar data/menu.json en el repo y hacer commit + push.

Nota

Esta es una versión demo: la edición se hace exportando el archivo a mano. En una implementación real para un cliente, este panel se conecta a una base de datos (Supabase o Google Sheets) y los cambios se ven al instante en el menú público, sin descargar ni subir nada.
